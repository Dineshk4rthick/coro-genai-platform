# Contoso IT Acceptable Use Policy

**Policy ID:** IT-USE-002  
**Effective date:** 1 January 2026  
**Policy owner:** Information Technology & Security

## 1. Purpose and scope

This policy defines the acceptable and safe use of Contoso computing equipment, software, networks, and communication systems by authorized users. It is a fictional policy created for testing the Contoso PolicyAssistant project and does not represent a real company's rules.

## 2. Authorized use and incidental personal use

Contoso technology infrastructure is provided primarily for official business purposes. Incidental personal use (such as brief personal email or checking online banking) is permitted provided it:
- Does not interfere with employee productivity or system performance.
- Does not incur operational costs to the company.
- Does not violate any existing Contoso code of conduct or data governance policy.

Contoso reserves the right to monitor, inspect, and log network traffic and system activity on all company-owned assets in accordance with local laws.

## 3. Prohibited activities

Users must not engage in any of the following activities on Contoso networks or devices:
- Downloading or running unauthorized third-party software, peer-to-peer applications, or cryptocurrency miners.
- Disabling security agents, endpoint detection software, or automated patch systems.
- Accessing, distributing, or storing illegal, offensive, or discriminatory content.
- Conducting penetration testing, network sniffing, or port scanning without formal authorization from the IT Security team.

## 4. Data handling and cloud storage

Confidential company records, source code, and customer personal data must only be stored on approved corporate cloud repositories (e.g., Contoso OneDrive, corporate SharePoint).

Uploading corporate intellectual property to unauthorized public cloud storage, external personal accounts, or unsanctioned third-party AI services without IT approval is strictly prohibited.

## 5. Removable media and peripheral devices

To mitigate malware introduction and data exfiltration, the use of personal USB flash drives and external hard drives is blocked by default on all Contoso workstations.

If removable storage is required for legitimate operational needs, employees must request an encrypted, company-provisioned drive through the IT Service Desk.

## 6. Responsibilities

Users are responsible for operating company devices responsibly, following software installation procedures, and reporting system warnings. IT Operations is responsible for maintenance, updates, and monitoring acceptable network utilization.

## 7. Questions and exceptions

Questions about approved software or technical policy interpretations should be directed to the IT Service Desk. Exceptions to workstation restrictions require written approval from the Head of IT Operations.
